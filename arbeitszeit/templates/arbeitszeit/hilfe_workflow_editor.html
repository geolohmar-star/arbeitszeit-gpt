Anleitung: Workflow-Editor

Wie Sie in PRIMA einen neuen Ablauf (Workflow) richtig anlegen — Schritt für Schritt, ohne technische Vorkenntnisse.

Was ist ein Workflow?

Ein Workflow beschreibt einen geregelten Ablauf — zum Beispiel: Eine Eingangsrechnung kommt an und muss von mehreren Personen geprüft, genehmigt und abgelegt werden.

In PRIMA können Sie solche Abläufe selbst im Workflow-Editor zusammenstellen, ohne dass jemand programmieren muss. Damit ein Workflow tatsächlich funktioniert, braucht er drei Pflichtbausteine:

Die drei Pflichtbausteine

1
Schritte anlegen — mit konkreter Zuständigkeit
Wer macht was?

Jeder Schritt steht für eine Aufgabe: Prüfen, Genehmigen, Bearbeiten, Informieren, Archivieren … Wichtig: Für jeden Schritt muss festgelegt werden, wer zuständig ist.

So legen Sie die Zuständigkeit fest:
  1. Im Workflow-Editor auf den Schritt klicken → Bearbeiten
  2. Im Feld Zuständigkeit die Option Spezifische Stelle wählen
  3. Im Feld Stelle das passende Kürzel aus dem Dropdown auswählen (z. B. al_fm für den Abteilungsleiter Facility Management)
  4. Speichern
⚠
Häufiger Fehler: Den Schritt benennen mit dem Kürzel im Titel (z. B. „al_fm – Prüfen"), aber das Dropdown-Feld Stelle leer lassen. PRIMA liest den Titel nicht aus — die Zuständigkeit muss im Dropdown eingetragen sein.
2
Schritte verbinden — mit Pfeilen (Übergänge)
In welcher Reihenfolge?

Schritte, die nicht durch Pfeile verbunden sind, bilden keinen Ablauf. Ohne Verbindungen weiß PRIMA nach dem ersten Schritt nicht, was als nächstes passieren soll — der Vorgang bleibt stehen.

So verbinden Sie Schritte:
  1. Im Workflow-Editor oben den Modus Verbinden aktivieren
  2. Den ersten Schritt anklicken (Startpunkt)
  3. Den zweiten Schritt anklicken (Zielpunkt) → ein Pfeil erscheint
  4. Im Dialog können Sie optional eine Bedingung eintragen (z. B. „nur wenn genehmigt"). Leer lassen = Pfeil gilt immer.
  5. Wiederholen bis alle Schritte verbunden sind: 1→2→3→…→Ende
⚠
Häufiger Fehler: Schritte angelegt, aber keine Pfeile gezogen. Der Workflow hat dann null Übergänge und kann nicht weiterlaufen. Kontrollieren Sie: Jeder Schritt außer dem letzten muss mindestens einen ausgehenden Pfeil haben.
3
Auslöser festlegen — wann startet der Workflow?
Was bringt den Ablauf in Gang?

Ein Workflow startet nicht von selbst. Er muss mit einem Auslöser (Trigger) verknüpft sein — also einem Ereignis, das PRIMA mitteilt: „Jetzt beginnt dieser Ablauf."

Die zwei Wege, einen Workflow auszulösen:
Weg A — Formular

Das Formular (z. B. ein Änderungsantrag) startet den Workflow automatisch beim Einreichen. Dazu muss im Formular-Editor unter Einstellungen → Workflow-Template dieser Workflow ausgewählt sein.

Weg B — DMS / Paperless

Ein eingehendes Dokument (Scan, E-Mail-Anhang) löst den Workflow aus. Dazu muss unter DMS → Einstellungen → Workflow-Regeln eine Regel angelegt sein, die das Dokument erkennt und diesen Workflow startet.

⚠
Häufiger Fehler: Im Workflow-Editor einen Auslöser-Namen eingetragen (z. B. „sonepar"), aber weder Formular noch DMS-Regel zeigt auf diesen Workflow. Der Name allein bewirkt nichts — er muss mit Weg A oder Weg B verknüpft sein.

Checkliste vor dem ersten Test

Gehen Sie diese Punkte durch, bevor Sie einen neuen Workflow in Betrieb nehmen:

  • ✓ Jeder Schritt hat im Feld Stelle einen konkreten Eintrag — nicht nur im Titel.
  • ✓ Alle Schritte sind durch Pfeile verbunden. Kontrollieren Sie jeden Schritt: Gibt es einen ausgehenden Pfeil zum nächsten?
  • ✓ Der Workflow ist über Formular oder DMS-Regel verknüpft — nicht nur als Name eingetragen.
  • ✓ Alle eingetragenen Stellen sind im HR-System besetzt (eine leere Stelle bedeutet: niemand bekommt die Aufgabe).
  • ✓ Der Workflow-Status steht auf Aktiv.
